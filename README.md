## 📱 Android Installation Guide

1. Download the `.apk` file onto your Android device or transfer it from your computer.
2. Tap the downloaded `.apk` file to start installation.
3. If prompted: **"Install unknown apps"**, allow permission for your browser or file manager.
4. Open **Axis** and enjoy instant offline productivity or sign in to sync with Firebase.
5. **Home Screen Widgets**: Long-press your phone's home screen, select **Widgets**, find **Axis**, and drag the widgets onto your screen:
   - **Daily Color Quick-Log Widget (2x1 / 2x2)**
   - **Salah Tracker Widget (4x2)**
   - **Today's Habits Checklist Widget (4x3)**

---

## 💻 Windows Installation Guide

1. Download the `axis-windows-setup-*.exe` installer.
2. Double-click the `.exe` file to run the installer.
3. If Windows SmartScreen displays a warning, click **More info** and then **Run anyway**.
4. Launch Axis from your desktop shortcut or Start Menu.

## ✨ Key Features

- **5-Color Self-Evaluation System**: Daily qualitative accountability scoring (Red, Orange, Yellow, Green, Gold).
- **Comprehensive Habit Engine**: Anchor habits, streak counters, completion percentages, and milestone celebrations.
- **Salah Tracker**: Track daily prayers (Solo / Bajamat / None) with custom audio reminders and home screen widgets.
- **Task Management**: Prioritized to-do lists with due dates, Google Calendar synchronization, and Quick Add FAB.
- **Native Android Widgets**: Zero-battery-drain Android RemoteViews widgets that operate seamlessly offline.
- **Cloud & Local Synchronization**: Seamless offline-first operation with optional Firebase cloud sync.
